# chunky_ww_cli

The chunky update commands for the `ww` command line of [wire_weaver](https://github.com/vhrdtech/wire_weaver): `flash` (delta, trial, confirm), `status`, `confirm`, `revert` and `reboot`, on a device that serves `ww_dfu` with chunky's `chunky_ww`. The `ww-chunky` binary (`ww_chunky/`) runs them.
